# Lyric Sentiment Analysis Example

This example demonstrates a basic sentiment analysis of song lyrics using a simple lexicon-based approach. It identifies positive and negative words within a given Turkish lyric to infer its overall emotional tone, mimicking the core concept of the LyricLens article. This self-contained Python script uses only standard library features to illustrate text analysis.

## Language

`python`

## How to Run

Save the code as main.py. Run from your terminal: python main.py
